EVENTEASE - EVENT MANAGEMENT SYSTEM
====================================

TECHNOLOGY
HTML5 + CSS3 + JavaScript only.
No npm, no backend and no external libraries are required.

RUN IN VS CODE + LIVE SERVER
1. Extract this folder.
2. Open the folder in VS Code.
3. Install the "Live Server" extension if needed.
4. Right-click index.html -> Open with Live Server.
5. Test the modules from the top navigation.

MODULES
- Home / upcoming events
- Registration / validation
- Login / logout
- Event details
- User event registration
- Admin event create/edit/delete
- Notifications
- Feedback
- Profile and registration history

IMPORTANT
This is a front-end academic project. Data is stored in browser LocalStorage.
To reset the demo completely, open browser DevTools -> Application -> Local Storage
and remove keys "eventease_data_v1" and "eventease_user", then refresh.
